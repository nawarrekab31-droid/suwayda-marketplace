الواجهة الخلفية

Node.js + TypeScript Express.js PostgreSQL Prisma ORM JWT Authentication RBAC كامل

تقدم المشروع حتى الآن

Phase 1: الأساس ✅

Monorepo، Docker، Prisma Schema، Seed Database، Auth + RBAC

Phase 2: لوحة المتجر ✅

Product Management، Images Upload (WebP)، Offers، Store Profile

Phase 3: العميل ✅

Home، Search، Product Page، Cart、Invoice、Checkout、Addresses

Phase 4: الطلبات والتوصيل ✅

State Machine، Merchant/Driver/Admin Dashboard، Notifications

جميع المراحل 1-4 مُنفَّذة بنجاح مع اختبارات كاملة (10 اختبارات نجحت).

نموذج حالة الطلب (State Machine)

التدفق الأساسي

NEW → ACCEPTED → PREPARING → READY → DRIVER → ON_THE_WAY → DELIVERED

حالات الجانب

REJECTED_BY_MERCHANT

CANCELLED_BY_CUSTOMER (قبل التجهيز)

DELIVERY_FAILED

التحقق من الصلاحية

✓ كل انتقال يُوثَّق في order_status_history

✓ middleware requireRole يحمي كل نقطة

✓ منع التغييرات غير المصرح بها

✓ تنبيهات تلقائية للجميع

أدوار المستخدمين والصلاحيات

ADMIN

• لا يمكن التسجيل عبر النظام

• يُنشأ عبر أمر seed CLI فقط

• إدارة جميع المتاجر والمستخدمين

• تفعيل/إلغاء المتاجر

• توثيق جميع العمليات (Audit Log)

MERCHANT

• التسجيل يتطلب موافقة ADMIN

• يرى فقط متجره الخاص

• إدارة منتجاته وعروضه

• معالجة طلبات المتجر فقط

CUSTOMER

• تصفح عام للمتاجر

• إنشاء سلة وطلبات

• تتبع الطلبات في الوقت الفعلي

• تقييم المتاجر بعد التوصيل

DRIVER

• لوحة بسيطة للتوصيلات المُخصصة

• تحديث حالة التوصيل

• مناقشة مشاكل التوصيل

بنية قاعدة البيانات

users, stores, products, categories

البيانات الأساسية مع فلاتر بحث فعّالة

orders, order_items, status_history

تتبع كامل للطلب مع توثيق البيانات

deliveries, drivers

ربط السائق بالطلب مع أوقات التوصيل

notifications, reviews

نظام الإشعانات وتقييم المتاجر

القواعد المهمة

  • السعر والبيانات تُقتبس في order_items (تثبيت الفاتورة)
  • الحذف الناعم (soft delete) على المتاجر والمنتجات
  • رقم الهاتف فريد كهوية ممثلة
  • العمولة: ليرة سورية (SYP)

القيمة المضافة للعميل

💼 للمنصة

• حل شامل بدون تعقيد التطبيقات الجانبية

• بنية موثوقة تُقاسم المتاجر المحلية

• نظام توصيل مخصص للمنطقة

• تحكم كامل بالبيانات (لا يتم إرسالها إلى الخارج)

👥 للعميل نهاية السلسلة

• تجربة عربية متكاملة وسهلة

• توثيق كامل للطلبات والفواتير

• موثوقية عالية بفضل تقييم المتاجر

• دعم محلي يفهم احتياجات السويداء
